# Heavenly Hands Handyman Services Website

Static one-page website ready for GitHub + Vercel.

## Upload steps
1. Create a new GitHub repository.
2. Upload all files from this folder.
3. In Vercel, import the GitHub repo.
4. Framework preset: Other / Static.
5. Build command: leave blank.
6. Output directory: leave blank or use `.`.
7. Connect the Porkbun domain in Vercel and add the DNS records Vercel gives you.
